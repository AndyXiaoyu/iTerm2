# 给官方 iTerm.app 注入中文（菜单栏 / 偏好设置 / 各窗口）

本文记录如何把中文界面**注入**到官方下载的英文版 `iTerm.app`，
让它在保留官方签名能力、可继续自动更新的前提下显示中文。

> 一键脚本：`scripts/apply_chinese_to_iterm.sh`
> 翻译资源：`Interfaces/localization/zh-Hans/*.strings`（67 个界面，基于 v3.6.11）

---

## 一、能做到什么 / 不能做到什么

| 界面 | 是否能汉化 | 说明 |
|------|-----------|------|
| 顶部菜单栏 | ✅ | 存在 `.nib`，可注入 |
| 偏好设置（⌘,） | ✅ | 存在 `.nib`，可注入 |
| 各窗口 / 面板 | ✅ | 共 67 个 `.nib`，可注入 |
| **右键终端的上下文菜单** | ❌ | 标题**硬编码在源码二进制**里，未走本地化机制，注入无法处理，保持英文。右键要中文只能改源码自行编译（即 `iTerm2.app` 的做法） |

---

## 二、为什么不能「就地」修改 /Applications/iTerm.app

`/Applications` 下经过公证的官方 app 带有防篡改属性（`com.apple.macl`）。
直接对它内部的 `.nib` 跑 `ibtool`，会出现：

- **删除旧 nib：成功**
- **写入新 nib：被系统拒绝（`Operation not permitted`）**

结果是 nib 被删掉却没写回，**app 被改坏**。

> ⚠️ 教训：绝不要直接对 `/Applications` 里的官方 app 就地注入。
> 正确做法是「拷到临时目录注入 → 重签 → 整体替换整个 .app」。

---

## 三、一键脚本用法（推荐）

```bash
# 1. 先完全退出 iTerm.app（整体替换需要移动 app）
# 2. 执行（默认目标 /Applications/iTerm.app）
./scripts/apply_chinese_to_iterm.sh

# 也可指定路径
./scripts/apply_chinese_to_iterm.sh /Applications/iTerm.app
```

脚本会自动完成：临时副本注入 → 保留 entitlements 重签 → 备份原版 → 整体替换 →
最终验证。任何一步失败都会**中止并回滚**，不会留下损坏的 app。

- 原版备份位置：`~/.iterm-zh/backup/iTerm.app.bak`
- 官方自动更新后界面会变回英文，**重跑本脚本即可恢复中文**。

---

## 四、手动步骤（脚本背后的原理）

```bash
APP=/Applications/iTerm.app
WORK=$(mktemp -d)/iTerm.app

# 1) 拷到可写的临时目录（ditto 能完整读取受保护 app）
ditto "$APP" "$WORK"
xattr -cr "$WORK"                     # 清除防篡改属性，使临时副本可写

# 2) 导出原 entitlements（保留摄像头/麦克风/自动化/JIT 等权限）
codesign -d --entitlements :/tmp/ent.plist "$APP"

# 3) 注入中文 nib（ibtool 用 zh-Hans/*.strings + 源 xib 重新编译 nib）
./scripts/inject_localization.sh "$WORK"

# 4) 保留 entitlements 的 ad-hoc 重新签名
codesign --force --deep --sign - --entitlements /tmp/ent.plist "$WORK"
codesign --verify --deep "$WORK"      # 必须通过

# 5) 备份原版后整体替换
ditto "$APP" "$HOME/.iterm-zh/backup/iTerm.app.bak"
mv "$APP" /tmp/iTerm.app.old          # 移走旧的（作回滚点）
ditto "$WORK" "$APP"                  # 放入注入好的中文版
```

注入的核心命令（见 `scripts/inject_localization.sh`）：

```bash
# 翻译文件转 UTF-16LE，再用源 xib + 中文 strings 重新编译出中文 nib
ibtool --import-strings-file <zh.strings> --compile <目标.nib> <源.xib>
```

## 五、验证方法

```bash
# 字节级检测 nib 里的中文（注意：必须 LC_ALL=C，否则会误判）
LC_ALL=C grep -ac "$(printf '\xe7\xaa\x97\xe5\x8f\xa3')" \
  /Applications/iTerm.app/Contents/Resources/MainMenu.nib   # >0 即含中文

codesign --verify --deep /Applications/iTerm.app            # 签名应通过
spctl -a -vv /Applications/iTerm.app                        # 应 accepted
```

**眼见为实**：完全退出 iTerm 后打开 `iTerm.app`，看菜单栏与 ⌘, 偏好设置是否中文。

> 注意：`iTerm.app` 与自编译的 `iTerm2.app` **bundle id 相同**（`com.googlecode.iterm2`），
> 若 `iTerm2.app` 正在运行，双击 `iTerm.app` 可能激活的是前者。
> 验证时建议先退出另一个，或用 `open -n /Applications/iTerm.app`。

## 六、回滚 / 恢复官方原版

```bash
# 用备份恢复（或用 ~/Downloads 里的官方安装包）
rm -rf /Applications/iTerm.app
ditto ~/.iterm-zh/backup/iTerm.app.bak /Applications/iTerm.app
```

## 七、踩坑记录（重要技术点）

1. **不能就地改官方 app** —— 防篡改保护会「删成功、写失败」，必须整体替换。
2. **检测 nib 中文必须用 `LC_ALL=C grep`** —— 在 UTF-8 locale 下，grep 对二进制
   文件里的 UTF-8 字节会误判为不匹配（`plutil -p`、`strings` 也读不可靠）。
3. **重签名要带 `--entitlements`** —— 否则会丢失摄像头/麦克风/自动化等权限。
4. **右键菜单无解** —— 源码硬编码，注入碰不到，只能改源码编译。
